So, I started a website. I'd been looking at other people's personal websites for a while, thinking "I want that," and finally got around to setting one up. I'm not sure what it will be yet—blog, digital garden, messy braindump—but I'll try to let it evolve with time and develop naturally. It's my place to put whatever I want.

Currently it's built using [Quartz](https://quartz.jzhao.xyz) with no changes to the default theme, and hosted using GitHub Pages. My next step is to make it my own: new colours, new fonts, new layouts, and maybe I'll even self-host at some point. Only time can tell, but whatever happens, I'll share all the interesting details right here.

I'm going to use this project as a way to tackle my perfectionism. Posts like these are a stream of consciousness and I'm limiting how much I go back and edit them. Hopefully I can build a habit of publishing things that are *good enough*, and so avoid the pits of "it will never be perfect so why even try?" I don't expect anyone to follow this, but if you do, I'm glad to have you along for the ride.

I struggle with endings too. Signing off, saying goodbye, that kind of thing. Bye for now.
